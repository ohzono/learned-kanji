# Security

`learned-kanji` has no runtime dependencies and performs no I/O: it does not touch the network, the file system, `eval`, or regular expressions. Its only input is the string you pass in, and every function runs in linear time.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting ("Report a vulnerability" on the Security tab of this repository) rather than a public issue. You can expect a first response within a week.

Only the latest published version is supported.
